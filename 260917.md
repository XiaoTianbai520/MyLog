## 1.jdk代理和代理类是平级关系，cglib代理和代理类是父子关系

因此cglib不能代理final类，因为final不能有子类。

方法也不能有final，因为代理是对方法进行重写。

## 2.动态代理的需求

1.首先是要解决就是方法的增强

2.当一个类里有多个方法时，我们要能精确调用，所以我们要将要增强的方法交给invoke，InvocatonHandler中只需要指定method‘方法要干什么事即可，这样不同方法来了直接传参就能知道给谁增强。

## 3.jdk代理只能给接口方法进行增强，cglib可以给类和接口

## 4.技巧，当我们不想重复创建对象时

可以使用静态变量，在静态代码块里进行初始化，但是有异常必须在代码块内处理

## 5.jdk动态代理是在运行阶段直接生成字节码进行类加载的

直接生成字节码的技术叫**asm**，在运行阶段把代理类转换成asm字节码。随后用类加载器进行加载，随后通过反射调用代理类的构造方法，创建实例。

```java
package com.itheima;

import java.io.FileOutputStream;
import java.lang.reflect.Constructor;
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;

public class TestProxy {
    public static void main(String[] args) throws Exception {
        byte[] dump = $Proxy0Dump.dump();

        /*FileOutputStream os = new FileOutputStream("$Proxy0.class");
        os.write(dump, 0, dump.length);
        os.close();*/

        ClassLoader loader = new ClassLoader() {
            @Override
            protected Class<?> findClass(String name) throws ClassNotFoundException {
                return super.defineClass(name, dump, 0, dump.length);
            }
        };
        Class<?> proxyClass = loader.loadClass("com.itheima.$Proxy0");

        Constructor<?> constructor = proxyClass.getConstructor(InvocationHandler.class);
        Foo proxy = (Foo) constructor.newInstance(new InvocationHandler() {
            @Override
            public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                System.out.println("before...");
                System.out.println("调用目标");
                return null;
            }
        });

        proxy.foo();
    }
}
```
